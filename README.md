# 🏏 IPL Analysis Dashboard (2008–2025)

This project showcases an **interactive Power BI dashboard** analyzing 18 years of IPL data to uncover key insights and trends.

## 🔍 Overview
The dashboard provides a comprehensive view of team performance, player achievements, and match statistics using clean, dynamic, and interactive visualizations.

## 📌 Key Features
- Season-wise **winners & runner-ups**  
- Detailed **points table** and team performance analysis  
- **Orange Cap & Purple Cap** (top performers) insights  
- Total **4s, 6s, matches, and venues** overview  
- Interactive filters and slicers for better exploration  
- Clean and user-friendly dashboard design  

## 📊 Insights You Can Derive
- Consistent **top-performing teams** across seasons  
- Player dominance in batting and bowling  
- Trends in **scoring patterns** (4s vs 6s)  
- Venue impact on match outcomes  

## ⚙️ Tools & Technologies
- Power BI  
- **DAX (Data Analysis Expressions)**  
- **Data Modeling**  
- **Power Query (ETL)**  
- Data Visualization Techniques  

## 🎯 Objective
To analyze IPL data from 2008 to 2025 and deliver meaningful insights on team performance, player statistics, and tournament trends using Power BI, DAX, and data modeling techniques.
